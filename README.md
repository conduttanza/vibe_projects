# Vibe projects that I used to learn coding with physics and math

**orbit_sim** contains three **basic** bidimensional orbital simulators, 
I made them for testing **PyGame** and **Python**'s approach with math

**PYGAME_WINDOW.py** is connected to **orbit.py** as orbit is the logic 
for the window to work, it is a circular orbit simulator with **customizable**
number of **planets**, their **masses** and their **distance** to a **sun**, customizable too.
